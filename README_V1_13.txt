MIQYAS v1.13 – واجهة الخدمات وخدمة المتاجر الإلكترونية

المحتويات:
- app.js و index.html: قائمة الخدمات المنسدلة ولوحة تسجيل المتاجر.
- sw.js: تحديث إصدار التخزين المؤقت.
- MIQYAS_ECOMMERCE_SCHEMA.sql: الجداول وسياسات القراءة/الإضافة الأساسية للمتاجر.

طريقة التركيب:
1) خذ نسخة احتياطية من المستودع الحالي.
2) نفّذ MIQYAS_ECOMMERCE_SCHEMA.sql في Supabase بعد التأكد أن ترقية v1.12 قد نُفذت وأن الدالة miqyas_has_active_subscription(uuid) موجودة.
3) استبدل app.js و index.html و sw.js في جذر main.
4) لا تستبدل config.js أو أي مفاتيح سرية.
5) افتح التطبيق وجرّب قائمة الخدمات. إضافة متجر تتطلب اشتراكاً فعالاً.

مهم جداً:
هذه المرحلة هي أساس إدارة المتاجر وتسجيلها. واجهة تسجيل المتجر لا تعني أن الربط مع المنصة قد اكتمل. لم يتم تفعيل Webhook receiver أو إرسال SMS/Email في هذه الحزمة؛ يلزم نشر Supabase Edge Function موثوقة والتحقق من توقيع كل منصة، وإعداد مزود رسائل، واختبار كل موصل قبل إظهار حالة "متصل".
لا تضع مفاتيح API السرية داخل app.js أو config.js العام.
منصات البداية عبر موصل Webhook/API موحد: سلة، زد، Shopify، WooCommerce، والمتجر الخاص.
