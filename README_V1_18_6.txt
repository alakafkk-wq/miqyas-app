MIQYAS v1.18.6 – إصلاح ظهور نوع النشاط عند إنشاء الحساب

التعديل:
- إظهار خيارات نوع النشاط (فروع / متجر إلكتروني) عند اختيار تبويب إنشاء حساب.

طريقة النشر: استبدال ملفات الحزمة في مستودع GitHub Pages بالملفات المحدثة.
