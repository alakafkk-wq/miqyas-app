مقياس MIQYAS – تحديث v1.14 (واجهة التواصل وإشعارات طلبات الاشتراك)

محتويات الحزمة
- index.html: إزالة بطاقة «بيانات المسجل في المنصة» من الواجهة، وإضافة أيقونات واتساب والبريد الإلكتروني، وإزالة خيار التحويل البنكي من واجهة الاشتراك.
- app.js: تفعيل روابط التواصل من إعدادات config.js، وإضافة إشعار فوري لمدير المنصة عند إدراج طلب اشتراك جديد عبر Supabase Realtime، وإزالة تعبئة بيانات الحساب الشخصي.
- sw.js: تحديث اسم ذاكرة التخزين المؤقت لإجبار المتصفح على جلب النسخة الجديدة.
- MIQYAS_V1_14_REALTIME_NOTIFICATIONS.sql: تفعيل نشر جدول طلبات الاشتراك إلى Supabase Realtime (إجراء آمن وقابل لإعادة التشغيل).

خطوات التحديث
1) احتفظ بنسخة احتياطية من ملفات المستودع الحالي.
2) استبدل index.html و app.js و sw.js في جذر المستودع بالملفات الموجودة في هذه الحزمة.
3) لا تستبدل config.js أو مفاتيح Supabase.
4) افتح Supabase > SQL Editor ونفّذ MIQYAS_V1_14_REALTIME_NOTIFICATIONS.sql مرة واحدة.
5) افتح المنصة بحساب مدير مقياس، ثم اضغط «تفعيل إشعارات الطلبات» واسمح بالإشعارات في المتصفح.
6) اختبر بوصول طلب جديد؛ الإشعار الفوري يعمل أثناء فتح المنصة والاتصال بها. الإشعارات عندما تكون المنصة مغلقة تتطلب Web Push مع VAPID ودالة إرسال خلفية، وهي ليست ضمن هذه الحزمة.

بيانات التواصل
أضف القيم العامة التالية إلى كائن window.MIQYAS_CONFIG الموجود مسبقاً في config.js، مع الإبقاء على إعدادات Supabase الحالية:
- CONTACT_EMAIL: بريد الدعم الذي تريد عرضه للعملاء.
- WHATSAPP_NUMBER: رقم واتساب بصيغة دولية أرقام فقط، مثال شكلي: 9665XXXXXXXX.
لا تضع أي مفاتيح سرية في config.js.

الدفع الإلكتروني
تمت إزالة خيار التحويل البنكي من واجهة العميل، وأصبحت الواجهة تعرض الدفع الإلكتروني فقط. زر الدفع متوقف مؤقتاً عمداً إلى أن يتم تحديد مزود الدفع وربطه من خلال Supabase Edge Function وحفظ المفاتيح السرية في Supabase Secrets. لا تُنشأ طلبات دفع وهمية ولا يتم تحصيل أي مبالغ في هذه المرحلة.
اختر مزوداً واحداً قبل إكمال الربط: Moyasar (ميسر)، Tap Payments، أو HyperPay.

ملاحظة
لم يتم تغيير الجداول أو بيانات المنشآت أو الفروع أو التقييمات أو الاشتراكات الحالية.
