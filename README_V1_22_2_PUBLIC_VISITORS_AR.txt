MIQYAS v1.22.2 – إحصائيات زوار رابط المنصة

ما الجديد:
- احتساب فتح رابط منصة MIQYAS قبل تسجيل الدخول أو إنشاء حساب.
- احتساب الزيارة مرة واحدة لكل جلسة تبويب باستخدام session_id عشوائي.
- تمييز المتصفحات الفريدة بمعرف عشوائي محفوظ محلياً.
- تقرير المدير يعرض إجمالي الزيارات والزوار الفريدين والعائدين والتوزيع اليومي.
- بيانات زوار رابط المنصة منفصلة عن زيارات مساحة عمل المشتركين.

الخصوصية:
- لا تُخزن الأسماء أو البريد أو أرقام الجوال أو معرفات الحساب أو عناوين IP.
- معرف الزائر ومعرف الجلسة UUID عشوائيان.
- الزائر الفريد يعني متصفحاً مميزاً وليس بالضرورة شخصاً واحداً.
- لا توجد بيانات تاريخية قبل نشر التحديث وتنفيذ SQL.

النشر:
1. خذ نسخة احتياطية من قاعدة البيانات وملفات الموقع.
2. نفّذ ملف MIQYAS_PLATFORM_VISITOR_ANALYTICS.sql المحدّث كاملاً في Supabase SQL Editor.
3. ارفع index.html وapp.js وstyle.css إلى الاستضافة.
4. افتح رابط المنصة من نافذة خاصة دون تسجيل الدخول، ثم افتحه مرة أخرى في جلسة جديدة.
5. ادخل بحساب مدير المنصة > إحصائيات الزوار > تحديث الإحصائيات.
6. اختبر تصدير Excel.

تنبيه بشأن الرسوم البيانية:
هذا التحديث يعالج تسجيل زوار الرابط. تصدير Excel الحالي ما زال يستخدم SheetJS Community Edition التي لا تنشئ مخططات Excel أصلية قابلة للتحرير؛ لذلك لم أصف الرسوم بأنها مكتملة. يتطلب اعتماد مخططات أصلية تغيير محرك إنشاء ملفات Excel والتحقق من جميع مسارات التصدير بشكل مستقل.
