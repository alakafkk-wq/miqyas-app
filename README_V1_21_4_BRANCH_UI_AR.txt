MIQYAS v1.21.4 — تحسين واجهة الفروع

التحديثات:
- إعادة تصميم بطاقات الفروع لتظهر بشكل أوضح على الجوال والكمبيوتر.
- تنظيم اسم الفرع والمنطقة/المدينة وعدد تقييمات العملاء.
- ترتيب إجراءات QR التقييم وQR خرائط Google وفتح الموقع وتحديث التقييمات والحذف.
- تحسين تباعد لوحة المؤشرات والخدمات على الشاشات الصغيرة.
- الحفاظ على معرّفات عناصر الواجهة وربط الأحداث الحالي ووظائف البيانات دون تغيير.

ملفات التعديل:
- index.html: تحسين عنوان قسم إدارة الفروع.
- style.css: إضافة تنسيقات متجاوبة للوحة الفروع والخدمات والمؤشرات.
- app.js: تحسين هيكل عرض بطاقة الفرع مع الإبقاء على نفس data attributes المستخدمة في الأحداث.

التحقق:
- تم التحقق من صياغة JavaScript باستخدام node --check.
- لم تُعدّل قاعدة البيانات أو ملفات SQL أو وظائف Supabase.
- لم تُعدّل إعدادات الدفع أو الاشتراكات أو روابط التقييم.
