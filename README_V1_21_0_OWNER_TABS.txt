MIQYAS v1.21.0 - تحسين تنظيم لوحة مالك المنصة

التحديث:
- تقسيم لوحة مالك المنصة إلى علامات تبويب: نظرة عامة، الاشتراكات والمشتركون، الفروع والتقييمات، التقارير والتصدير، المنشآت، سجلات الحركة.
- عرض قسم واحد في كل مرة لتقليل طول الصفحة وتحسين الاستخدام على الجوال.
- الإبقاء على معرفات العناصر والأزرار الحالية حتى تستمر وظائف JavaScript والتقارير دون تغيير.
- تحديث مفتاح ذاكرة Service Worker لضمان تحميل ملفات الواجهة الجديدة.

طريقة النشر عبر GitHub:
1. فك ضغط الحزمة.
2. انسخ محتويات مجلد miqyas_v1_21_0_work إلى جذر المستودع مع استبدال الملفات المطابقة.
3. ارفع التعديلات إلى main بالطريقة المعتادة.

لم يتم تعديل SQL أو Supabase أو بوابة الدفع. لم يتم تنفيذ نشر GitHub من هذه الحزمة.
