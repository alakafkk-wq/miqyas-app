MIQYAS v1.21.2 — تحديث الإدارة والاستعراض

هذا التحديث مبني على ملفات MIQYAS v1.21.1 المرفوعة في المحادثة، ويحافظ على ملفات التشغيل الحالية (config.js وstyle.css وmanifest وPWA وملفات Supabase).

التغييرات:
1) إظهار عدد الفروع والمتاجر لكل منشأة في قائمة المنشآت والمشتركين.
2) تفعيل زر «استعراض» لمدير المنصة لعرض بيانات المنشأة وفروعها وتقييمات الفروع ومتاجرها وطلباتها وتقييمات المتاجر.
3) تقرير Excel للمنشأة بأوراق مستقلة للملخص والفروع وتقييمات الفروع والمتاجر وتقييمات المتاجر.
4) إضافة حذف المتجر مع تأكيد كتابة اسم المتجر. يسمح الإجراء لمدير المنصة أو مالك المنشأة، ويحذف الطلبات والدعوات والتقييمات وبيانات اعتماد المتجر التابعة له فقط.
5) تحسين تحميل القوائم على دفعات حتى لا تتوقف الإحصائيات عند حد نتائج Supabase الافتراضي (1000 سجل).
6) تحديث اسم ذاكرة PWA المؤقتة حتى يحصل المستخدمون على ملفات الواجهة الجديدة بعد النشر.

قبل النشر:
- خذ نسخة احتياطية من مستودع Git وقاعدة بيانات Supabase.
- لا تستبدل config.js بملف مختلف ولا تضع مفاتيح Secret في ملفات الواجهة.
- راجع MIQYAS_V1_21_2_ADMIN_EXPLORER.sql ثم نفذه مرة واحدة في Supabase SQL Editor.
- ارفع كامل محتويات هذا المجلد إلى جذر المستودع مع الحفاظ على إعدادات النشر الحالية.
- اختبر بحساب مدير المنصة: ظهور الأعداد، فتح استعراض منشأة، تصدير Excel، وحذف متجر تجريبي فقط.
- اختبر بحساب مالك منشأة: حذف متجر تابع لمنشأته فقط، وتأكد أن متجر منشأة أخرى لا يمكن حذفه.

حدود هذا الإصدار:
- لم يتم الاتصال بمشروع Supabase الفعلي أو تنفيذ SQL أو النشر إلى Git من هذه البيئة.
- لم يتم إكمال تكامل تقييم المتاجر من Webhook سلة حتى إرسال الدعوة بعد 24 ساعة. لا تعتبر هذه الميزة جاهزة للإطلاق ضمن هذه الحزمة.
- لم يتم تعديل صفحة تقييم الفروع العامة أو إعدادات Paylink وResend.
- فحص JavaScript المحلي وفحص بنية HTML ووجود المعرفات الأساسية اجتازا الفحص. يلزم اختبار التكامل الفعلي بعد النشر التجريبي.
