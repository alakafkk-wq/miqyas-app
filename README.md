# MIQYAS v1.10 — إدارة المشتركين

## التحديث
- إضافة لوحة «إدارة المشتركين» لمدير المنصة فقط.
- عرض جميع اشتراكات المنشآت مع الباقة والحالة وتواريخ البداية والنهاية.
- تعديل الباقة والحالة والمدة.
- إيقاف الاشتراك مؤقتاً وإعادة تفعيله.
- حذف سجل الاشتراك فقط، دون حذف المنشأة أو الفروع أو المستخدمين أو التقييمات أو طلبات الدفع.
- سجل تدقيق يسجل العملية والمنفذ والتاريخ والبيانات السابقة واللاحقة.

## ملفات النشر
استبدل في جذر مستودع GitHub:
- `index.html`
- `app.js`
- `sw.js`

لا تستبدل `config.js` أو ملفات البيانات الأخرى.

## إعداد قاعدة البيانات
قبل استخدام لوحة إدارة المشتركين، افتح Supabase SQL Editor ونفّذ الملف:
`MIQYAS_V1_10_PLATFORM_SUBSCRIBER_MANAGEMENT.sql`

الملف يضيف سياسة قراءة المنشآت لمدير المنصة، حالة الإيقاف المؤقت، جدول سجل التدقيق، ودالة آمنة تتحقق من `is_platform_admin()` داخل قاعدة البيانات.

## ملاحظات أمان
- لا تعتمد الحماية على إخفاء الأزرار فقط؛ جميع عمليات الإدارة تمر عبر دالة SQL بصلاحية مدير المنصة.
- حذف الاشتراك يزيل صف الاشتراك فقط، ويحتفظ بسجل التدقيق وباقي بيانات المنشأة.
- لا تنفذ أي حذف للمنشأة أو الفروع أو المستخدمين أو التقييمات.


## v1.11 إدارة المنشآت والحذف النهائي
- أضيفت قائمة بجميع المنشآت في لوحة مدير المنصة.
- يتطلب الحذف تأكيداً مزدوجاً: موافقة ثم كتابة اسم المنشأة حرفياً.
- ينفذ الحذف عبر دالة Supabase المقيدة بمدير المنصة فقط.
- تُحذف بيانات المنشأة المرتبطة عبر علاقات CASCADE.
- لا تُحذف حسابات Auth تلقائياً؛ قد تكون مرتبطة بمنشآت أخرى.
- ملف MIQYAS_ORGANIZATION_DELETE.sql يعيد إنشاء وظيفة الحذف فقط ولا يحذف بيانات عند تشغيله.
