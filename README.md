# MIQYAS – تحديث صوت العميل والتقارير

يتضمن هذا التحديث:
- اعتماد تقييمات العملاء المرسلة عبر QR وحدها في مؤشرات صوت العميل ورضا العملاء.
- فصل عدد سجلات الجودة عن عدد تقييمات العملاء.
- إظهار تعليق العميل أو ملاحظة سجل الجودة في جدول التفاصيل.
- عرض التاريخ والوقت لكل تقييم.
- إضافة فلاتر تاريخ البداية والنهاية مع فلتر المنطقة والفرع.
- جعل ورقة Excel المسماة «صوت العميل» خاصة بتقييمات QR فقط، مع التعليقات والتاريخ والفرع.
- إبقاء سجلات الجودة محفوظة في ورقة مستقلة وعدم حذف أي بيانات.

## النشر
استبدل الملفات `app.js` و`index.html` و`sw.js` في مستودع GitHub الحالي بالملفات الموجودة في الحزمة، ثم انتظر تحديث GitHub Pages وافتح الموقع مع تحديث قوي/مسح ذاكرة الصفحة إن لزم. لا يتطلب هذا التعديل تشغيل SQL أو تغيير قاعدة بيانات Supabase.

## توضيح الاحتساب
«تقييمات العملاء» هو عدد سجلات QR المستلمة، وليس عدد أشخاص فريدين؛ لأن النموذج الحالي لا يطلب رقم جوال أو هوية للتحقق من تفرّد الشخص.
