مؤشر MIQYAS Cloud - الإصدار 1.0

قبل التشغيل:
1) افتح config.js.
2) ضع Publishable Key الذي يبدأ بـ sb_publishable_ مكان PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE.
3) لا تضع Secret Key أو service_role في هذا الملف.
4) ارفع مجلد miqyas_cloud إلى استضافة HTTPS ثابتة. يمكن استخدام استضافة مجانية تدعم المواقع الثابتة.
5) افتح الرابط من الهاتف.

الميزات:
- تسجيل حساب بالبريد وكلمة المرور عبر Supabase Auth.
- تسجيل الدخول والخروج.
- إنشاء مساحة منشأة عبر RPC create_organization.
- إضافة الفروع وحفظها في Supabase.
- إضافة تقييمات VOC والمتسوق السري والتقييم الداخلي.
- قراءة بيانات المنشأة والفروع والتقييمات وفق سياسات RLS.
- واجهة عربية متجاوبة وPWA.

إعدادات Supabase:
- Project URL مضبوط مسبقاً في config.js.
- يلزم إدخال Publishable Key فقط.
- تأكيد البريد الإلكتروني مفعل: بعد التسجيل تحقق من البريد، ثم سجل الدخول.
- في Authentication > URL Configuration أضف رابط موقعك ضمن Site URL وRedirect URLs بعد نشره.

ملاحظات أمنية مهمة:
- المفتاح الموجود في المتصفح هو Publishable Key فقط؛ لا تستخدم مفاتيح Secret أو service_role في الواجهة.
- سياسات RLS الحالية تتيح لأعضاء المنشأة قراءة بياناتها، والمدير/المالك إدارة الفروع. يجب إجراء اختبار عزل بحسابين مختلفين قبل استخدام بيانات حقيقية.
- هذه نسخة تشغيل أولى؛ لا تشمل دعوات الموظفين وإدارة الأدوار من الواجهة أو الدفع الإلكتروني أو استعادة كلمة المرور.
- النتيجة الحالية للتقييم تحتسب نسبة الإيجابي من مجموع الإيجابي والمحايد والسلبي. أوزان جودة الفروع المتقدمة ستضاف لاحقاً.
- بيانات الحسابات والمنشآت والفروع والتقييمات تحفظ في Supabase، أما ملفات الواجهة فتستضاف على خدمة استضافة ثابتة.
